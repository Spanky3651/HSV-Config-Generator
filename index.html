What this tool does

click to fold once you know it

Hit Score Visualizer (HSV) is a Beat Saber mod that draws the floating number you see each time you slice a block. That number's size, color, wording, and thresholds all come from a config.json file. This free HSV config generator and editor lets you edit every part of that file visually, preview exactly how a cut will look in-game, and then download the file or push it straight to your Quest over USB.

◈How a cut is scored: every slice is worth up to 115 points - up to 70 for your pre-swing angle, 15 for how close to center you cut, and 30 for your follow-through. Each judgment tier below says "if the total cut score is at least this threshold, draw the number using this text and color."

Judgment Manager

0 tiers
These are the score bands. When you slice a block, HSV reads down this list from the top and uses the first tier whose threshold your cut score reaches. So a 115 cut uses the top tier; a 108 cut falls through to the first tier at 105 or below. Each tier sets the threshold (minimum score), the text template (what's drawn, using the tokens below), and the color. Order matters - keep thresholds descending (use Sort desc if they drift). Fade is HSV's color-lerp: the tier's color blends toward the tier above it as the score climbs - the spectrum bar below shows the exact color at every score.

Global Settings

Advanced
Settings that apply to the whole config. Display Mode decides how the score is shown: format fills in your %-tokens (the normal choice) and numeric shows just the score. textOnly, scoreOnTop and directions show the template literally without filling tokens, so they suit plain label text. default is what HSV does when the file has no display mode at all: your label with the score under it. Leave the version fields as-is unless you know you need them.

Bad Cuts & Misses

Optional text shown instead of the game's own when you miss a note or make a bad cut (wrong direction, wrong saber color, or a bomb). Leave a list empty to keep the game's default. Tokens like %s are not filled in here, but rich-text tags work. Preview them with the Miss and Bad cut buttons in the preview.

Chains (Burst Sliders)

A chain is an arrow block followed by a trail of small links. The head scores up to 85 (70 pre-swing + 15 accuracy, no follow-through) and every link is a flat 20. Leave both off and the game shows its normal chain scores. Preview them with the Chain head and Chain link buttons in the preview.

Text Token Reference

Inside a tier's text template, these % tokens get replaced with live values when you cut a block. Click a chip to insert it into the template you last clicked in. Hover any chip for its meaning. Lowercase = raw numbers; uppercase = the text swaps from the Sub-Judgments panel.
%s %p %b %c %a %B %C %A %t %d %T %n %%
Rich text (TextMeshPro): <size=200%>…</size> · <color=#1e6bff>…</color> · <b> · <i> · <u> · <s> · <alpha=#80> · <mark> · <sup> · <sub> · <cspace> · <voffset> · <rotate> · <br> and the rest of the TextMeshPro set. Unknown tags print as plain text, same as in game.
Characters: the game font may lack some symbols and draw them as empty boxes. The preview cannot detect that, so test unusual symbols in game.
Scoring model: pre-swing max 70 + accuracy max 15 + post-swing max 30 = 115.

Stream fires a quick burst of cuts (your replay cuts when one is loaded) to check that the text stays readable at speed. Replay mimics the in-game decay - pop in, drift upward, fade out - then rests visible for editing. It also plays the follow-through: the score starts without it and climbs (Intermediate updates on) or jumps once at the end (off), or starts from a full 30 with Assume max post-swing. Colors include the Fade blend. Releasing a slider re-triggers the replay; clicking the spectrum bar jumps the sim to any score.

    ⚠ USB BUS LOCKED // ADB CONFLICT DETECTED

    webusb interface claim failed

    Chrome couldn't claim the Quest's ADB interface. Only one program can own it at a time - a background ADB server from SideQuest, Meta Quest Link, Android Studio, or a terminal adb session is almost certainly holding it. Kill it, then retry.

    Windows · CMD or PowerShell
    adb kill-server
    taskkill /F /IM adb.exe
    macOS / Linux
    adb kill-server
    killall adb
    1. Unplug the Quest from this PC.
    2. Copy a command above and run it in a terminal to kill the background ADB server. Fully quit SideQuest / Meta Quest Link / Android Studio if they're running - they restart the server.
    3. Replug the USB cable, then hit Retry WebUSB Connection.
