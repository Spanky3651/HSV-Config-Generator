What this tool does

Hit Score Visualizer (HSV) is a Beat Saber mod that draws the floating number you see each time you slice a block. That number's size, color, wording, and thresholds all come from a config.json file. This builder lets you edit every part of that file visually, preview exactly how a cut will look in-game, and then either download the file or push it straight to your Quest over USB.

◈How a cut is scored: every slice is worth up to 115 points - up to 70 for your pre-swing angle, 15 for how close to center you cut, and 30 for your follow-through. Each judgment tier below says "if the total cut score is at least this threshold, draw the number using this text and color."

Global Settings

Settings that apply to the whole config. Display Mode decides how the score is shown: format uses your custom text templates (the normal choice), numeric shows just the plain number, textOnly shows your text but hides the numbers, and scoreOnRelease waits until your swing finishes before updating. Leave the version fields as-is unless you know you need them.

Judgment Manager

0 tiers
These are the score bands. When you slice a block, HSV reads down this list from the top and uses the first tier whose threshold your cut score reaches. So a 115 cut uses the top tier; a 108 cut falls through to the first tier at 105 or below. Each tier sets the threshold (minimum score), the text template (what's drawn, using the tokens below), and the color. Order matters - keep thresholds descending (use Sort desc if they drift). Fade is HSV's color-lerp: the tier's color blends toward the tier above it as the score climbs - the spectrum bar below shows the exact color at every score.

Send to Quest

Disconnected
Pushes the config straight onto your headset over the USB cable - no BMBF, no file manager, no sideloading app. It speaks the same ADB-over-WebUSB protocol ModsBeforeFriday uses, right from the browser.
▲
  1. On the Quest, enable Developer Mode (Meta Quest phone app → your headset → Developer Mode → on).
  2. Plug the headset into this PC with a USB-C cable. Inside the headset, approve "Allow USB debugging" when it pops up (tick Always allow).
  3. Beat Saber must have been launched at least once with HSV installed, so the Configs folder exists.
  4. Click Connect, pick your headset in Chrome's device list, then Push config.

Not working? Read this
"Push to Quest" is greyed out or says WebUSB unavailable - WebUSB needs desktop Chrome or Edge (Firefox and Safari don't support it), and the app must be in its own browser tab, not embedded inside another page. Open the app directly and try again.

Headset never appears in the picker - the cable must carry data (some charge-only cables don't), Developer Mode must be on, and you must accept the USB-debugging prompt inside the headset. Make sure no other ADB tool (SideQuest, BMBF, a terminal adb) is holding the connection - only one can own it at a time.

"Configs folder not found" - launch Beat Saber once with HSV installed so the mod creates its folder, then try again. You can also point Destination folder anywhere you like.

In-game - after pushing, open Beat Saber → Mods → HitScoreVisualizer and select the config (or reload) to apply it.

Validation

Live checks on your config. Errors mean the file won't behave as intended (e.g. a duplicate threshold that's unreachable); warnings are things worth a look. A clean config shows a single green check.

⚠ USB BUS LOCKED // ADB CONFLICT DETECTED

webusb interface claim failed

Chrome couldn't claim the Quest's ADB interface. Only one program can own it at a time - a background ADB server from SideQuest, Meta Quest Link, Android Studio, or a terminal adb session is almost certainly holding it. Kill it, then retry.

Windows · CMD or PowerShell
adb kill-server
taskkill /F /IM adb.exe
macOS / Linux
adb kill-server
killall adb
  1. Unplug the Quest from this PC.
  2. Copy a command above and run it in a terminal to kill the background ADB server. Fully quit SideQuest / Meta Quest Link / Android Studio if they're running - they restart the server.
  3. Replug the USB cable, then hit Retry WebUSB Connection.
